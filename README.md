# JavaScript Amazon Clone

A fully functional Amazon-inspired e-commerce website built with **HTML, CSS, and Vanilla JavaScript**. The project recreates a modern online shopping experience, featuring a dynamic product catalog, shopping cart, checkout flow, order history, and package tracking.

This project emphasizes modular JavaScript architecture, DOM manipulation, asynchronous programming, and clean code organization.

---

## Features

- Product catalog with dynamic rendering
- Product search functionality
- Shopping cart with persistent storage using Local Storage
- Quantity updates and item removal
- Multiple delivery options with dynamic shipping costs
- Automatic tax and order total calculations
- Checkout page with real-time payment summary
- Order placement using a backend API
- Orders history page
- Package tracking page with estimated delivery dates
- Responsive layout for desktop and mobile devices

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/javascript-amazon-clone.git
```

Navigate into the project:

```bash
cd javascript-amazon-clone
```

Open `amazon.html` in your browser or run the project using a local development server.
